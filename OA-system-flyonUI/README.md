菜单结构：10 大模块、近 40 个页面——工作台、我的待办（4个子tab）、审批中心（请假/出差/加班/报销/用印/采购/流程设置）、行政办公（公告/会议/会议室预订/车辆/资产/用品）、人事管理（组织架构/员工档案/考勤/招聘/培训/薪资）、财务管理、知识库、项目管理（含看板）、统计报表、系统设置（用户/角色/菜单/部门/日志）、个人中心。

其中 15 个左右是专门定制的页面（工作台仪表盘、请假申请全流程表单、组织架构树图、会议室预订时段网格、考勤日历、任务看板、审批效率统计图表、菜单管理读取真实配置等），其余列表类页面统一复用一个 GenericListPage 组件 + 模拟数据驱动，保证每个菜单点进去都有真实内容而不是空白页。
