快捷复制组件演示

统一样式的「层叠矩形」复制图标，覆盖代码块、对话气泡、表格、列表、输入框、正文段落六种常见场景。点击图标即可复制对应内容，成功后图标会短暂变为对勾。

代码块

按钮固定在右上角，常见于 AI 回答中的代码区域。

function greet(name) {
  return `Hello, ${name}!`;
}

console.log(greet("World"));

对话气泡

鼠标悬浮（或聚焦）在消息上时，底部工具栏淡入显示。

当然可以。快捷复制的关键在于：图标要低调，只在需要时出现；点击后要给出明确的成功反馈，比如切换成对勾图标或弹出提示条。

文本输入框

按钮固定在控件右侧，复制的是当前输入框内的实时值，而非初始值。

正文段落
